Simulation:
- AC Peak Voltage: 100V
- Frequency: 50Hz/60Hz
- Sweep/Transient time: 40ms

Behavior Analysis:

Without capacitor:
The output waveform is full-wave rectified but not smooth.
It contains ripple because the voltage drops between peaks.

With capacitor:
The capacitor charges at peak voltage and discharges slowly.
This reduces ripple and produces smoother DC output.

Conclusion:
Adding a capacitor improves DC smoothing but ripple still exists depending on capacitor value.
